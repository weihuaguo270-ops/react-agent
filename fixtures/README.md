# Fixtures

Shared JSON / patch / corpus fixtures for harness, software tasks, failure-regression,
and application demos. Consumed by `scripts/eval/**`, tests, and offline app paths.

| Path | Purpose |
|------|---------|
| `expense/` | Expense app: claims, policy corpus, business-eval cases |
| `rag_corpus/` | Generic offline RAG demo docs (non-expense) |
| `docs_troubleshoot/` | Docs-troubleshoot evidence / production corpus / traces |
| `software_tasks/` | Software-task runner fixtures |
| `failure_regression/` | Failure-regression trajectory samples |
