# Core Module Tests

Tests for the core runtime components of react-agent.

## Structure

- `test_react_loop.py` - ReAct loop functionality
- `test_orchestrator.py` - Multi-agent orchestration
- `test_planner.py` - Task planning and decomposition
- `test_tools.py` - Tool registry and management
- `test_llm.py` - LLM provider integration
- `test_context.py` - Context management
- `test_memory.py` - Memory system
- `test_cot.py` - Chain-of-thought reasoning
- `test_workflow.py` - Workflow execution
- `test_resilience.py` - Resilience and ToolGuard
- `test_tool_scope.py` - Tool scope management
- `test_write_sets.py` - Write conflict detection

## Related Directories

- `tests/apps/` - Application-specific tests
- `tests/harness/` - Harness and trajectory tests (if created)
- `tests/safety/` - Safety and permissions tests (if created)
