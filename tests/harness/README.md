# Harness Tests

Tests for the Harness execution and trajectory recording system.

## Structure

- `test_harness_r2.py` - Harness R2 requirements
- `test_sandbox.py` - Sandbox isolation tests
- `test_recorder.py` - Trajectory recording
- `test_replay.py` - Trajectory replay
- `test_deterministic_replay.py` - Deterministic replay verification
- `test_runtime_observability.py` - Runtime observability

## Related

These tests verify the Format B trajectory contract defined in `schemas/harness_trajectory.schema.json`.
