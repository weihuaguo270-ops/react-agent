# 项目背景与对外边界

本仓库承载企业内部智能工作助手（work-assistant）的工程原型。仓库名与英文工作名统一为 work-assistant；Python 分发名 react-agent、包名 react_agent、命令和环境变量保留兼容名称。主场景是规范咨询（docs_troubleshoot），第二场景是报销办理（expense）；两者属于同一员工工作助手。

S0–S8 已按现有证据完成原型验收，当前不新增验收切片；不改评测仓，也不由此推断生产可发布。

2026-11-16 已放弃发布门槛「3 个项目、30 条真实任务、10 条独立 held-out」。现有离线评测与质量配件闭环保留为原型证据。不再为 llm-eval-engine 与 trace-debugger 补齐跨仓账本 golden 或 held-out，也不把这两个评测仓写成简历上的第三项。本仓简历简介仍只描述工作助手；库存预占属于另仓，不在本仓简历中展开。放弃该门槛不表示现有评测已达生产成熟度。

## 对外口径

可以表述为可部署、可评测的 Agent 应用工程原型，包含权限闸门、人工审批、轨迹记录、业务终态和跨仓质量验收。现有离线评测、golden/故障/生产盲测入口和轨迹闭环是原型评估证据。

不能表述为：

- 已在企业生产环境形成长期线上流量或 SLA；
- 生产 SaaS、多租户权限平台或自动根因诊断系统；
- 合成任务、离线评测、κ 或 external_real_sandbox 成功率等于生产业务成功率；
- trace-debugger 或 llm-eval-engine 是工作助手本身，或简历上的第三项产品；
- change-delivery 仍是本仓业务线或跨仓闭环的默认入口；
- 已放弃的「3 个项目、30 条真实任务、10 条独立 held-out」门槛已被现有评测补齐，或因此达到生产成熟度。

`change-delivery`（受控变更交付）已独立且已停止，不再作为本仓业务线；本仓已移除其文档附录与运行入口。
