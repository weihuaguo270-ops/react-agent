# 项目背景

定位：受控 Agent 运行时，主验证方向为软件工程交付，兼顾客服工作流与 RAG。

## 对外口径

可以表述为带权限闸门、轨迹、回归评测和 Docker 容器隔离的 Agent 工程原型，并已在受控业务任务和公开 GitHub 数据上完成可复现验证。

不能表述为：

- 已在企业生产环境部署或形成长期线上流量
- 已证明人工成本、收入或生产 SLA 改善
- 受控夹具成功率等于真实业务成功率
- Docker live-check 不等于企业安全认证
- 自建子集结果等于完整 SWE-bench 榜单结果

## 边界

不宣称生产 SaaS、长期线上 SLA、企业多租户权限或自动根因诊断。
