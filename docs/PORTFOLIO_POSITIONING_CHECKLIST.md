# 三仓对外口径检查清单

## 1 分钟检查

- [ ] 外人能说出使用者：企业内部员工。
- [ ] 外人能说出两件事：规范咨询、报销办理。
- [ ] work-assistant 是主产品名；react-agent 只是过渡仓库名。
- [ ] 没有把“三大业务线”或“通用 Agent 框架”放在首页主标题。
- [ ] change-delivery 被描述为规划中的独立项目，不与两个主场景并列。
- [ ] trace-debugger 被描述为轨迹失败雷达与 CI 钩子。
- [ ] llm-eval-engine 被描述为发版前自检，输出 pass/review/hold。
- [ ] 闭环顺序是：产出轨迹 → trace-debugger → llm-eval-engine。

## 证据边界

- [ ] 所有公共入口保留“可部署、可评测的工程原型”。
- [ ] 明确证据包含合成任务与 external_real_sandbox。
- [ ] 没有把离线 κ、黄金集数量、模型榜或沙箱结果写成生产 SLA。
- [ ] 没有宣称生产 SaaS、多租户、长期线上流量或企业权限体系。

## 文件边界

- [ ] 本阶段不拆 Git 仓库、不迁移 GitHub 交付代码。
- [ ] 不重写 Agent 循环，不删除评测脚本或评测集。
- [ ] 历史报告和归档材料只作为证据引用，不作为首页产品名。
