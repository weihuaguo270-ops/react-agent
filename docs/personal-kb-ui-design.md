# 个人知识库界面设计规范

## 一、设计目标

将企业内部「个人知识库」从功能表单改造为可长期工作的文档工作区，对齐 Open Notebook 形态：
- **一边是文档**：可浏览、打开阅读、编辑的文档库
- **一边是 Agent**：可随时对话的智能助手
- **基本单位是文档和摘要**，不是标题/关键词卡片

员工确认身份后进入稳定的多栏工作区，加入资料、浏览文档和对话是同一空间内的动作，不是要先进场、用完再退回的功能切换。

---

## 二、整体架构

### 2.1 页面层级

```
┌─ 身份入口页（未确认时）
└─ 工作区（确认后）
   ├─ 顶栏（身份信息 + 全局操作）
   ├─ 提示横幅（未配置模型、检索不可用等全局状态）
   └─ 三栏主工作区
      ├─ 左栏：文档库（列表 + 快速操作）
      ├─ 中栏：阅读/详情区（打开某份文档时显示）
      └─ 右栏：Agent 对话区
```

### 2.2 布局原则

- **宽屏（>1200px）**：三栏同时显示，中栏可折叠（未打开文档时隐藏）
- **中屏（900-1200px）**：左栏 + 右栏常驻，中栏浮层或覆盖
- **窄屏（<900px）**：标签页切换（文档库 / 对话 / 阅读），但不退回单页滚动

### 2.3 视觉风格

- **内部办公工具**：安静、可读、留白充足
- **色彩系统**：
  - 主色：中性蓝（#2563eb），用于强调和链接
  - 背景：浅灰（#f4f6f9）和纯白（#ffffff）
  - 边框：柔和灰（#e2e8f0）
  - 文本：深灰（#0f172a）和中灰（#64748b）
  - 状态色：绿（成功）、红（错误）、黄（警告）、蓝（信息）
- **字号**：
  - 正文 14px，辅助文字 12px
  - 标题层级：页面标题 20px，模块标题 16px，文档标题 15px
- **圆角**：统一 8-10px
- **间距**：基础间距 8px，模块间距 16-20px

## 三、关键界面设计

### 3.1 身份入口页

**场景**：用户首次打开或切换身份时

**布局**：
```
┌────────────────────────────────────────┐
│ 页面头部                                │
│   个人知识库                            │
│   副标题：确认身份后进入工作区...       │
├────────────────────────────────────────┤
│                                        │
│   ┌──────────────────────────┐        │
│   │ 确认身份                  │        │
│   │                          │        │
│   │ 员工身份（X-Actor-Id）    │        │
│   │ [__________________]     │        │
│   │                          │        │
│   │ 提示：身份对本次使用有效... │        │
│   │                          │        │
│   │ [确认身份，进入工作区]    │        │
│   └──────────────────────────┘        │
│                                        │
└────────────────────────────────────────┘
```

**文案**：
- 标题：**个人知识库**
- 副标题：确认身份后进入工作区：一边是我的文档，一边是可对话的 Agent
- 输入框标签：**员工身份（X-Actor-Id）**
- 占位符：例如 employee-1
- 提示：身份对本次使用有效。不同身份的文档相互隔离，你只能看到自己的文档。
- 按钮：**确认身份，进入工作区**

**交互**：
1. 输入框为空时点击按钮，显示错误提示："请填写员工身份"
2. 格式非法时显示："身份格式应为字母数字及 ._- 符号，不超过 64 字符"
3. 确认成功后立即进入工作区，加载该身份的文档列表

### 3.2 工作区 - 顶栏

**场景**：进入工作区后始终可见

**布局**：
```
┌────────────────────────────────────────────────────────┐
│ 当前身份：employee-1    [更换身份] [刷新文档] [关于]  │
└────────────────────────────────────────────────────────┘
```

**文案**：
- 当前身份：**{actor_id}**
- 按钮文案：更换身份 / 刷新文档 / 关于

**交互**：
- 点击"更换身份"：提示"更换身份后当前对话将清空，确认继续？"，确认后返回身份入口页
- 点击"刷新文档"：重新加载左栏文档列表
- 点击"关于"：显示系统版本、模型状态等信息（可选）

---

### 3.3 提示横幅

**场景**：有全局状态需要告知时显示

**类型 1：未配置模型**
```
┌────────────────────────────────────────────────────────┐
│ ⚠ 当前未接入灵活对话与联网生成所需的模型。你仍可以把链  │
│   接、PDF 或本地文件加入个人库，但无法使用 Agent 对话、  │
│   改写摘要或联网生成文档。                              │
│   配置方法：设置 REACT_AGENT_SERVER_LLM=1             │
└────────────────────────────────────────────────────────┘
```

**类型 2：网络检索不可用**
```
┌────────────────────────────────────────────────────────┐
│ ℹ 网络检索服务当前不可用，无法执行联网生成任务。          │
└────────────────────────────────────────────────────────┘
```

**类型 3：切换身份后**
```
┌────────────────────────────────────────────────────────┐
│ ✓ 已切换到身份 employee-2，对话已重置，文档库已更新。   │
└────────────────────────────────────────────────────────┘
```

### 3.4 左栏：文档库

**场景**：当前身份下的所有文档

**布局**：
```
┌────────────────────────────┐
│ 我的文档 (12)              │
│ [+ 加入] [⟳]              │
├────────────────────────────┤
│                            │
│ ┌────────────────────────┐ │
│ │ [链接] 如何配置开发环境  │ │
│ │                        │ │
│ │ 本文介绍了如何在本地搭建 │ │
│ │ 开发环境，包括 Python... │ │
│ │                        │ │
│ │ 来源：https://...      │ │
│ │ 2025-01-15  1,240 字   │ │
│ └────────────────────────┘ │
│                            │
│ ┌────────────────────────┐ │
│ │ [PDF] 产品需求文档 v2   │ │
│ │                        │ │
│ │ 本次更新重点关注用户反馈 │ │
│ │ 中提到的三个核心问题...  │ │
│ │                        │ │
│ │ 来源：requirements.pdf │ │
│ │ 2025-01-14  3,580 字   │ │
│ └────────────────────────┘ │
│                            │
│ （空状态见 3.5）            │
│                            │
└────────────────────────────┘
```

**文档卡片元素**：
- **类型标签**：[链接] / [PDF] / [文件] / [正文] / [Agent]，用小标签区分
- **标题**：15px，加粗，最多两行截断
- **摘要**：13px，浅灰色，最多三行截断
- **元信息**：12px，更浅的灰
  - 来源：URL（可点击）或文件名或"无外部来源"
  - 日期：更新时间或加入时间
  - 字数：正文字符数
  - 状态：草稿（如果 draft=true）

**交互**：
- **点击卡片**：在中栏打开文档详情（标题、摘要、正文可滚动阅读）
- **悬停效果**：边框高亮，轻微提升阴影
- **右键或长按**：显示操作菜单（打开 / 编辑 / 删除 / 分享链接）

**顶部操作**：
- **[+ 加入]**：点击后显示浮层或下拉面板，支持：
  - 粘贴 https 链接
  - 选择本地文件（PDF / TXT / MD / HTML）
  - 粘贴正文
  - 拖拽文件到此区域
- **[⟳]**：刷新文档列表

### 3.6 中栏：阅读/详情区

**场景**：从左栏点击某份文档后，在中栏展开阅读

**布局**：
```
┌────────────────────────────────────┐
│ ← 返回列表            [编辑] [×]  │
├────────────────────────────────────┤
│                                    │
│ [链接] 如何配置开发环境             │
│                                    │
│ 来源：https://example.com/setup    │
│ 更新于 2025-01-15  1,240 字        │
│                                    │
├────────────────────────────────────┤
│ 摘要                                │
│                                    │
│ 本文介绍了如何在本地搭建开发环境，  │
│ 包括 Python 虚拟环境、依赖安装和   │
│ 常见问题排查...                    │
│                                    │
├────────────────────────────────────┤
│ 正文                                │
│                                    │
│ ## 准备工作                        │
│                                    │
│ 在开始之前，请确保已安装 Python    │
│ 3.9 或更高版本。可以通过以下命令   │
│ 检查当前版本：                     │
│                                    │
│ ```                                │
│ python --version                   │
│ ```                                │
│                                    │
│ ## 创建虚拟环境                    │
│                                    │
│ （正文可滚动，支持 Markdown 渲染） │
│                                    │
│                                    │
└────────────────────────────────────┘
```

**元素说明**：
- **顶部工具栏**：
  - ← 返回列表（窄屏必需，宽屏可选）
  - [编辑]：切换到编辑模式
  - [×]：关闭阅读区，回到左栏+右栏布局
- **文档头部**：
  - 类型标签 + 标题
  - 来源链接（可点击跳转）
  - 元信息（更新时间、字数）
- **摘要区**：
  - 标题："摘要"
  - 摘要内容，完整展示，不截断
- **正文区**：
  - 标题："正文"
  - 正文内容，支持滚动
  - 支持 Markdown 渲染（代码块、列表、标题等）

**交互**：
- **编辑模式**：点击"编辑"后，标题、摘要、正文变为可编辑输入框
  - 显示"保存"和"取消"按钮
  - 保存后自动刷新左栏列表和中栏显示
- **关闭**：点击 [×] 或按 ESC 键关闭中栏，左栏和右栏自动扩展

│ [________________________]         │

### 3.8 右栏：Agent 对话区

**场景**：始终显示，用户可随时与 Agent 对话

**布局**：
```
┌────────────────────────────────────┐
│ 知识库助手                          │
├────────────────────────────────────┤
│                                    │
│ ┌────────────────────────────┐    │
│ │ 你好。我是你的知识库助手，  │    │
│ │ 可以帮你加入资料、改写摘要、│    │
│ │ 回答问题，也可以检索网上信息│    │
│ │ 生成文档。                  │    │
│ └────────────────────────────┘    │
│                                    │
│          ┌─────────────────┐      │
│          │ 你好             │      │
│          └─────────────────┘      │
│                                    │
│ ┌────────────────────────────┐    │
│ │ 你好！有什么可以帮你的吗？  │    │
│ └────────────────────────────┘    │
│                                    │
│          ┌─────────────────┐      │
│          │ 帮我整理这段笔记 │      │
│          │ https://...      │      │
│          └─────────────────┘      │
│                                    │
│ ┌────────────────────────────┐    │
│ │ 好的，我来帮你整理...       │    │
│ │ [思考过程]                  │    │
│ │ 已加入文档「笔记标题」      │    │
│ └────────────────────────────┘    │
│                                    │
│ （对话区可滚动）                    │
│                                    │
├────────────────────────────────────┤
│ [_____________________________]    │
│ [发送] [清空对话]                  │
└────────────────────────────────────┘
```

**元素说明**：
- **对话气泡**：
  - 用户消息：右对齐，蓝色背景
  - Agent 消息：左对齐，白色背景带边框
  - 错误消息：左对齐，浅红背景
  - 警告消息：左对齐，浅黄背景
- **消息类型**：
  - 普通对话：黑色文本
  - 操作结果："已加入文档..."、"已保存..."等，可带链接
  - 引用：显示引用的文档标题和链接
  - 错误："个人库中没有足够依据"、"网络检索不可用"等
- **输入区**：
  - 多行输入框（自动扩展，最多 5 行）
  - 支持 Shift+Enter 换行，Enter 发送
  - 占位符："问我任何问题，或发送链接、粘贴正文..."
- **操作按钮**：
  - [发送]：主按钮
  - [清空对话]：次要按钮，点击后提示"确认清空对话记录？"

**特殊消息展示**：

**1. 思考过程（可折叠）**

```

**2. 引用展示**
```

│ 根据你的文档「如何配置开发环境」│

### 3.10 对话：依据不足

**场景**：用户提问，但个人库中没有相关文档

**消息示例**：
```
┌────────────────────────────────┐
│ 个人库中没有足够依据回答这个问题│
│                                │
│ 你可以：                        │
│ • 换个问法重新提问              │
│ • 加入相关资料后再提问          │
│ • 要求我检索网上信息并生成文档  │
└────────────────────────────────┘
```

**文案要点**：
- 明确说明"个人库中没有足够依据"
- 提供后续操作建议
- 不要编造答案或用内置语料代替

┌─────────────────────────────────┐

│                                 │
│ ▸ 工作步骤（点击展开）           │
│                                 │
│ 正在检索...                     │
└─────────────────────────────────┘

Agent：
┌─────────────────────────────────┐
│ 已检索到 3 条相关信息，正在整理  │
│ 文档...                         │
└─────────────────────────────────┘

Agent：
┌─────────────────────────────────┐
│ 文档已生成，请确认：             │
│                                 │
│ ▾ 文档预览                       │
│   标题：Python 虚拟环境使用指南  │
│   摘要：本文介绍了如何使用 Python│

## 六、交互逻辑

### 6.1 加入资料的四种方式

1. **通过左栏「+ 加入」面板**：
   - 填写 URL / 正文 / 选择文件
   - 点击"加入个人库"
   - API：`POST /v1/docs/personal/ingest`

2. **通过 Agent 对话发送链接**：
   - 用户：`https://example.com/article`
   - Agent 调用 `personal_upsert_document`
   - 回复："已加入文档「文章标题」→ 打开文档"

3. **通过 Agent 对话粘贴正文**：
   - 用户：`帮我整理这段笔记：[粘贴正文]`
   - Agent 调用 `personal_upsert_document`
   - 回复："已加入文档「笔记标题」"

4. **拖拽文件到左栏**：
   - 监听 `drop` 事件
   - 读取文件内容（Base64）
   - 调用加入 API

### 6.2 打开文档

**流程**：
1. 用户点击左栏文档卡片
2. 中栏展开，显示加载状态
3. 调用 `GET /v1/docs/personal/documents/{id}`
4. 渲染标题、摘要、正文
5. 左栏和右栏缩小（宽屏）或保持不变（中屏）

**关闭**：
- 点击中栏 [×] 按钮
- 点击中栏外部区域（可选）
- 按 ESC 键
- 切换身份时自动关闭

### 6.3 编辑文档

**流程**：
1. 在中栏阅读模式下点击"编辑"
2. 标题、摘要、正文变为输入框
3. 修改内容
4. 点击"保存更改"：
   - 调用 `POST /v1/docs/personal/documents/{id}`
   - 成功后显示"已保存"
   - 返回阅读模式，内容已更新
   - 刷新左栏列表（标题或摘要可能变化）
5. 点击"取消"：放弃修改，返回阅读模式

### 6.4 Agent 对话

**基本流程**：
1. 用户在右栏输入框输入消息
2. 点击"发送"或按 Enter
3. 用户消息添加到对话气泡（右对齐）
4. 显示"正在思考..."（可选）
5. 调用 `POST /v1/docs/personal/agent/chat`
6. Agent 回复添加到对话气泡（左对齐）
7. 如有引用，显示引用列表
8. 如有工具步骤，显示可折叠的"思考过程"

**特殊场景**：
- **加入资料**：回复中包含"已加入文档「标题」→ 打开文档"，点击链接可打开中栏
- **生成文档**：回复中包含文档预览和"保存到个人库"按钮，点击后调用 `personal_save_generated_document`
- **依据不足**：回复样式变为警告（浅黄背景）
- **错误**：回复样式变为错误（浅红背景）

### 6.5 更换身份

**流程**：
1. 点击顶栏"更换身份"
2. 弹出确认对话框："更换身份后当前对话将清空，文档库将切换到新身份。确认继续？"
3. 点击"确认"：
   - 返回身份入口页
   - 清空 `currentActor`
   - 重置对话区
   - 清空文档列表
4. 点击"取消"：保持当前状态

### 6.6 刷新文档

**流程**：
1. 点击左栏顶部"⟳"或顶栏"刷新文档"
2. 调用 `GET /v1/docs/personal/documents`
3. 更新左栏文档列表
4. 如果当前打开的文档已被删除，关闭中栏并提示"该文档已不存在"

## 七、实现建议

### 7.1 技术栈

保持当前单文件 HTML + 原生 JavaScript 的方式，或升级到：
- **现代框架**：Vue 3 / React / Svelte（如果需要更好的状态管理）
- **样式**：TailwindCSS 或继续内联样式
- **构建**：Vite（如果需要模块化）

### 7.2 组件拆分

建议拆分为以下组件（如果使用框架）：
- `IdentityView`：身份入口页
- `WorkspaceView`：工作区容器
  - `TopBar`：顶栏
  - `Banner`：提示横幅
  - `DocumentList`：文档库（左栏）
  - `DocumentDetail`：阅读/详情区（中栏）
  - `AgentChat`：对话区（右栏）
- `IngestPanel`：加入资料面板
- `DocumentCard`：单个文档卡片

### 7.3 状态管理

关键状态：
- `currentActor`：当前身份
- `documents`：文档列表
- `currentDocumentId`：当前打开的文档 ID
- `chatMessages`：对话记录
- `llmAvailable`：模型是否可用
- `isLoading`：各种加载状态

### 7.4 API 封装

建议封装 API 调用：
```javascript
const api = {
  // 文档
  listDocuments: (actorId) => fetch(...),
  getDocument: (actorId, docId) => fetch(...),
  ingestDocument: (actorId, payload) => fetch(...),
  updateDocument: (actorId, docId, fields) => fetch(...),
  
  // Agent
  chat: (actorId, message) => fetch(...),
  
  // 系统
  getInfo: () => fetch(...),
};
```

### 7.5 可访问性

- 所有交互元素支持键盘操作
- 输入框有明确的 `label` 或 `aria-label`
- 对话气泡有 `role="log"` 或 `aria-live="polite"`
- 错误提示用 `role="alert"`
- 按钮有明确的 `aria-label`（如关闭按钮）

### 7.6 性能优化

- 文档列表虚拟滚动（如果文档数量 > 100）
- 对话记录懒加载（如果消息数量 > 50）
- 防抖输入框（搜索功能，如果后续添加）
- 图片懒加载（如果文档支持图片）

## 附录：设计原则总结

1. **工作区 > 功能表单**：稳定的多栏布局，不要来回切换
2. **文档 > 卡片**：基本单位是完整的文档（标题、摘要、正文），不是字段列表
3. **自然对话 > 柜台流程**：Agent 对话应该像聊天，不要做成"先选功能，再填表单"
4. **明确失败 > 假装成功**：未配置模型时不假装对话，依据不足时明确拒答
5. **引导 > 报错**：空状态给出明确的下一步操作建议
6. **保存进库 > 导出文件**：生成的文档保存到个人库工作区，不是本地文件路径
7. **可读 > 花哨**：内部工具风格，排版清晰，不要做成营销页面
